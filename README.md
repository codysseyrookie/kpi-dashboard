# KPI Desk 샘플 앱

월·부서별 목표와 실적을 비교하는 정적 KPI 대시보드입니다. 기존 `02_실습자료`는 유지하고 앱을 `실습앱`에 별도로 만들었습니다.

## 실행 방법

`index.html`을 최신 브라우저에서 직접 여세요. 개발 서버와 외부 라이브러리가 필요하지 않습니다. 기본 샘플은 2026-09/2026-10의 영업A·B·C 6건이며, 전체 목표 합계 60,000,000원·실적 합계 59,400,000원·달성률 99%입니다. 필터 입력은 `localStorage`에 저장되며 실제 DB에는 전송되지 않습니다. 브라우저 저장소를 비우면 추가 입력이 사라지고 기본 샘플이 다시 표시됩니다.

`index.html`에서 헤더의 테마 선택기를 사용하면 Sunrise와 Ink & Blue 디자인을 한 페이지에서 전환할 수 있습니다. 선택한 테마는 브라우저에 기억됩니다. 개별 시안 미리보기는 `02-sunrise.html`과 `03-ink-blue.html`을 열면 됩니다. 세 디자인은 같은 샘플 데이터와 동작 코드를 사용합니다.

## 파일 역할

- `index.html`: 페이지 구조, 요약, 필터, 테마 선택기, 근거표, 입력 대화상자
- `style.css`: 데스크톱·모바일 화면
- `app.js`: 화면 동작과 필터·합계 표시
- `data/repository.js`: 샘플 데이터 읽기·저장 adapter. 다음 단계에서 Supabase 접근 계층으로 교체할 경계입니다.
- `02-sunrise.html`: 주황·산호색의 밝은 Sunrise 디자인
- `03-ink-blue.html`: 코발트 블루와 네이비 중심의 Ink & Blue 디자인
- `styles/shared.css`: 공통 벡터·플랫 스타일, Pretendard·Material Symbols 설정
- `styles/01-meadow.css`, `styles/02-sunrise.css`, `styles/03-ink-blue.css`: 각 버전별 색상과 도형
- `styles/switchable-themes.css`: 한 페이지 테마 선택기가 사용하는 Sunrise·Ink & Blue 테마
- `styles/theme-polish.css`: 테마 선택기 스타일

## 계산과 입력 규칙

- 달성률은 선택 결과의 실적 합계 ÷ 목표 합계 × 100입니다. 행별 달성률의 평균을 사용하지 않습니다.
- 합산 목표가 0원이면 `목표 미설정`을 표시합니다.
- 월은 유효한 `YYYY-MM`, 부서명은 앞뒤 공백을 정리한 1~80자, 금액은 0 이상의 안전한 정수(원)로 검사합니다.
- 같은 월과 부서의 중복 입력은 거부합니다. 빈 결과와 데이터 읽기 오류도 구분합니다.

## 글꼴과 아이콘

Pretendard와 Google Material Symbols Rounded를 Google Fonts에서 불러옵니다. 따라서 두 리소스는 온라인 상태에서 표시되며, 오프라인에서는 시스템 한글 글꼴과 아이콘 텍스트 대체값을 사용합니다. 앱은 외부 JavaScript 패키지를 사용하지 않습니다.

## 다음 단계의 Supabase 연결

현재 앱은 로그인, 설정 파일 읽기, 네트워크 요청, DB 연결을 하지 않습니다. 제공된 `02_실습자료/schema.sql`도 참고 자료로만 두었고 DB에서 실행하지 않았습니다. Supabase 연결 단계에서 인증·설정·사용자별 접근을 검토한 후 `data/repository.js`를 교체할 수 있습니다. 기존 교육 자료나 DB 설정은 이 앱에 복사하지 않았습니다.
